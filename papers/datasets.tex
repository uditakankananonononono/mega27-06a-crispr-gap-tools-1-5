\section{Datasets}
\label{sec:data}
All datasets are public; URLs and access dates are in
Appendix~\ref{sec:repro}. No simulated or synthetic outcome data is used anywhere in this work.

\subsection{Doench FC+RES and V1 (on-target, Rule Set 2 family)}
The flow-cytometry FC+RES screen (Doench et al.\ 2016) measures the
activity of ${\sim}$1.8k guides targeting surface-protein genes by
fluorescence shift. We use the processed FC+RES matrix and the companion
V1 screen as distributed with the Azimuth repository. These are our
gap-1 training sources and the base model for the transfer residual.

\subsection{DeepHF three-nuclease screens}
The DeepHF resource (Wang et al.\ 2019) provides genome-scale activity
measurements for three SpCas9 variants (WT, eSpCas9, SpCas9-HF1) over
${\sim}$54k--59k guides each, together with per-guide biofeatures
(chromatin accessibility, gene context). The three screens measure the
same guide library under different nucleases, which enables the matched
residual analysis of Section~\ref{sec:discovery}; guide identity across
screens is established by sequence matching, as the released arrays are
not in a common order (see Section~\ref{sec:discovery} and commit history
for the pairing correction).

\subsection{crisprSQL off-target corpus}
crisprSQL (St\"ortz \& Minary 2021) is a curated database of measured
CRISPR off-target cleavage sites aggregated from 17 studies. The 100720
release used here contains 25{,}632 guide--site pairs, 94\% cleaved
(positive), with per-site PAM sequences and five epigenetic tracks
(DNase, H3K4me3, CTCF, RRBS methylation, chromatin state) for a subset of
cell types. 47\% of measured off-targets carry non-NGG PAMs, which
motivates gap 4.

\subsection{CRISPRscan zebrafish in-vivo screen}
CRISPRscan (Moreno-Mateos et al.\ 2015, Nat Methods; PMC4589495) measures
in-vivo indel activity of sgRNAs injected with Cas9 mRNA into zebrafish
embryos (in-vitro-transcribed guides, no cell culture). We use the
492-guide activity table (Nature ESM MOESM633, sheet d1 joined to sheet a
sequences) as the seventh gap-1 assay family; the Europe PMC deposit was
an empty placeholder, so files were fetched from the publisher ESM links.

\subsection{PRIDICT2 pegRNA library}
The PRIDICT2 dataset (Mathis et al.\ 2023) contains ${\sim}$23k pegRNA
designs with measured prime-editing efficiencies in HEK293T and K562
cells, with sequence context and design features (PBS/RTT lengths,
edit type, position). Used for gap 3.

\subsection{CFD scoring matrices}
The CFD per-position substitution frequencies (Doench et al.\ 2016) are
taken from the CRISPOR source tree (Haeussler \& Konczak 2016) and
vendored into \texttt{crisprgap/matrices/} so the scorer is reproducible
offline.

\subsection{Haeussler 2016 CRISPOR benchmark}
Haeussler et al.\ 2016 (Genome Biol; via the microsoft/Elevation mirror)
provides 26{,}052 guide--site pairs with read-fraction labels used as the
gap-2 external validation corpus; 2{,}550 pairs overlap crisprSQL and are
excluded, leaving 23{,}502 external pairs with only eight positives.

\subsection{DeepCRISPR regression screens}
The DeepCRISPR release (Chuai et al.\ 2018, Genome Biol; bm2-lab
\texttt{paper\_data-regression}) contains guide-level efficacy screens for
HCT116 (4{,}239), HEK293T (4{,}566), HeLa (8{,}101) and HL60 (2{,}076)
as 23-mers with scores in $[0,1]$ -- the eighth through eleventh gap-1
assay families (Wang-2014 and Xu-2015 derivatives plus a
DeepCRISPR-compiled HEK293T set). The same release's off-target tables
(\texttt{offtar/*.repiotrt}, 153k pairs) were examined and \emph{not}
integrated: 25 of their 29 unique guides (86\%) are already in crisprSQL
(Tsai-2015 GUIDE-seq and kin), so adding them would double-count.

\subsection{DepMap 23Q4 guide efficacy}
DepMap 23Q4 Public (figshare article 24667905), file
\texttt{CRISPRInferredGuideEfficacy.csv}: Chronos-inferred per-guide
efficacy for 193{,}475 guides pooled across $>$1{,}000 screened cell
models; lengths 19/20/23, scores in $[0,1]$. The twelfth gap-1 family.
