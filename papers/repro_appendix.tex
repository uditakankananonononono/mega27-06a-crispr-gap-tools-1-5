\appendix
\section{Reproducibility appendix}
\label{sec:repro}

\subsection{Environment}
All experiments ran on a single CPU container: Python 3.10.12,
NumPy 2.2.6, SciPy 1.15.3, scikit-learn 1.7.2, PyTorch 2.14.0 (CPU),
pandas 2.3.3, ViennaRNA 2.7.2 (Python bindings). No GPU, no paid API, no
rate-limited service was used. The full pipeline (all five gaps, the
discovery analysis, the PORTA correction, bootstrap intervals, and every
figure in this paper) completes in under one hour on this hardware.

\subsection{Data provenance}
\begin{itemize}
\item \textbf{Doench FC+RES / V1}: Azimuth mirrors at
\texttt{github.com/MicrosoftResearch/azimuth} (\texttt{FC\_plus\_RES.csv},
\texttt{V1\_suppl\_data.txt}); retrieved 2026-09-24.
\item \textbf{DeepHF screens}: pickled arrays at
\texttt{github.com/dagrate/public\_data\_crisprCas9}
(\texttt{data/deepHF/\{wt,esp,hf\}\_seq\_data\_array.pkl}); retrieved
2026-09-24. The three arrays are \emph{not} in a common guide order;
cross-screen analyses match guides by sequence string (53{,}937 three-way
matched guides). An index-based pairing produces spurious null concordance and
was caught and corrected during figure review.
\item \textbf{crisprSQL}: release 100720 from \texttt{crisprsql.com};
25{,}632 guide--site pairs, 17 studies.
\item \textbf{PRIDICT2}: \texttt{data\_23k\_v1.csv} from
\texttt{github.com/uzh-dqbm-cmi/PRIDICT2}, \texttt{dataset/proc\_v2/}.
\item \textbf{CFD matrices}: vendored from
\texttt{github.com/maximilianh/crisporWebsite} (\texttt{CFD\_Scoring/})
into \texttt{crisprgap/matrices/}.
\end{itemize}

\subsection{Entry points and tests}
\begin{verbatim}
scripts/fetch_data.sh                      # dataset retrieval
python -m crisprgap.train_efficacy         # gap 1 models
python scripts/run_crossdata_cnn.py        # gap 1 CNN transfer matrix
python -m crisprgap.train_offtarget        # gap 2 GNN + baselines
python -m crisprgap.train_offtarget_ablation  # gaps 4-5 channels
python -m crisprgap.train_pegrna           # gap 3 ridge/scratch/transfer
python -m pytest tests/                    # 61 hermetic tests, offline
python scripts/make_paper_assets.py        # tables and figures from results/
python scripts/make_audit_tables.py        # routing + per-seed ablation tables
python experiments/study_routing.py        # gap-2 routing audit (falsification)
python experiments/ablation_multiseed.py   # gaps 4-5 five-seed aggregate
python experiments/rna_features_pegrna.py finalize  # seqfold/primer3 features
python -m crisprgap cfd <wt23> <off23>     # CLI: CFD score (JSON out)
python -m crisprgap mit <guide> <off>      # CLI: MIT score (JSON out)
python -m crisprgap calibrate scores.csv --fit platt
\end{verbatim}
Every number in the paper is regenerated from \texttt{results/*.json} by
\texttt{make\_paper\_assets.py}; no number is typed by hand. Split seeds,
group keys and model seeds are logged in each JSON sidecar.

\subsection{Negative results register}
Preserved negatives: (i) CNN negative transfer Doench$\to$DeepHF
($-0.25$); (ii) pooled training fails both directions; (iii) pegRNA
Cas9-transfer never beats scratch at any $n \in \{250, 1000, 4000\}$ in
either cell line; (iv) PAM and chromatin channels do not beat
seq-only beyond split noise (five seeded splits); (v) the
crisprSQL-derived PAM-activity atlas ties CFD out-of-sample; (vi) three
thermodynamic feature channels (ViennaRNA MFE, seqfold $\Delta G$,
primer3 $T_m$) add nothing to pegRNA prediction ($\le 10^{-4}$
Spearman); (vii) study routing on crisprSQL is falsified (router
$=$ always-MIT; oracle headroom $0.001$); (viii) torch init alone spans
AUROC $0.530$--$0.606$ and ECE $0.209$--$0.389$ on a fixed split.
