\paragraph{Toward the 40-tool / 120-dataset bar.}
Reachable additions with genuine use in this item: published-model
external validation (PRIDICT2, CRISPRon, DeepHF BiLSTM weights as
benchmark columns), verification tools (primer3-py pegRNA thermodynamics,
seqfold cross-check, FlashFry off-target aggregation, BLAST+ guide
uniqueness), and the wider public CRISPR screen literature (Kim-2019/2020
CRISPRon 15k, Xiang-2021, Chari-2015, GUIDE-seq/CIRCLE-seq/CHANGE-seq
primaries, inDelphi, SPROUT, TUSCAN, DeepCpf1). We estimate an honest
ceiling of ${\sim}$35 tools and ${\sim}$60 accession-level datasets for
this item; beyond that, entries would be decorative, so they are not
claimed.

\paragraph{Examined and not integrated (with reasons).}
Chari 2015 (nmeth.3473): Nature ESM MOESM297--302 checked -- gene-level
rates and indel spectra only; the guide-level activity table is not in
the publisher deposits. The author's repository (rajchari2/sgrnascorer)
does ship the sgRNAScorer~2.0 high/low training lists (215+215 guides),
now integrated as an external discrimination test (Section gap-1).
Koike-Yusa 2014 (nbt.2800): ESM MOESM7 is the 87k-guide library design
without screen outcomes; outcome counts would need GEO reprocessing
(deferred); the MiSeq off-target table was integrated (gap~4). OPED (Zenodo 8133527): 126k-pegRNA design
database with predicted (not measured) efficiencies -- no labels.
DeepPrime (Yu 2023, Cell): 259k-pegRNA training set not fetchable
(publisher page bot-walled, no PMC/Zenodo deposit); models only.
DeepCRISPR off-target tables: 86\% of guides already in crisprSQL
(duplicate). Microsoft Elevation: package build fails on modern Python.
DeepCpf1: only a 500-row pre-encoded demo table available.
